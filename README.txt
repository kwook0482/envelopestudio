봉투 디자인 제작소 - 7차 수정본

실행
1. ZIP 압축을 풉니다.
2. index.html을 Chrome 또는 Edge에서 엽니다.
3. 1단계에서 조건을 입력하고 앞면·상단 덮개 프롬프트를 각각 복사합니다.
4. 외부 이미지 생성 AI에서 앞면과 상단 덮개 이미지를 각각 생성합니다.
5. 2단계에서 이미지를 업로드하고 필요하면 배치를 조절합니다.
6. 3단계에서 A4 가로 미리보기를 확인하고 인쇄 또는 PDF 저장을 선택합니다.

5차 주요 수정
- 사용자가 업로드한 envelope-template.svg를 기준 원본으로 반영
- 도안 외곽선 및 접는 선을 업로드 원본의 좌표와 형상에 맞춰 구성
- 앞면 이미지는 앞면 185 × 75mm 사각 영역 안에서만 표시
- 상단 덮개 이미지는 185 × 30mm 영역 안에서만 표시
- SVG clipPath를 적용해 이미지가 봉투 영역 밖으로 보이지 않도록 제한
- 상단 덮개 이미지 생성 권장 크기를 191 × 36mm(약 3mm 여유)로 변경
- 업로드 시 중앙의 185 × 30mm만 표시하도록 하고 기본 맞춤을 '영역 채우기'로 설정
- 상단 덮개는 문자가 없는 단색 바탕 이미지만 생성하도록 변경
- 덮개 이미지에 문자·글자·숫자·로고 등 모든 텍스트 요소를 넣지 않도록 프롬프트에 명시
- 덮개는 지정한 단색 바탕만 허용하며 문구·문자·장식·패턴·그라데이션 등을 금지
- 덮개 이미지는 기존 설정대로 180도 회전
- 최종 출력 SVG를 A4 가로(297 × 210mm) 실제 비율로 구성하고 봉투 도안을 중앙 배치해 비율 왜곡 방지

상단 덮개 이미지 생성 안내
- 권장 캔버스: 1910 × 360px
- 최종 표시 영역: 185 × 30mm
- 글자와 중요한 요소는 가장자리에서 약 3mm 안쪽에 배치하도록 AI에 요청합니다.
- AI 이미지 생성 서비스가 한글 문구를 잘못 표현할 수 있으므로 업로드 전에 문구를 확인하세요.
- AI가 생성한 글꼴·문구가 상표, 로고, 기존 작품을 모방하지 않도록 프롬프트에 제한을 넣었습니다. 다만 이 문구만으로 모든 권리 침해 가능성이 법적으로 보장되는 것은 아닙니다. 상업적 사용 전에는 문구·상표·이미지 권리를 별도로 확인하세요.

출력
- 인쇄 창에서 A4, 가로 방향, 배율 100% 또는 실제 크기를 선택하세요.
- '페이지에 맞춤'은 선택하지 마세요.
- PDF 저장은 브라우저 인쇄 창에서 'PDF로 저장'을 선택하는 방식입니다.
- 실제 출력 후 자로 전체 도안이 225 × 170mm인지 확인하세요.

주의
- 191 × 36mm는 덮개 이미지의 권장 생성 크기이며 AI가 정확한 픽셀/비율을 항상 보장하지는 않습니다.
- AI가 권장 비율과 다르게 생성한 경우 '영역 채우기'가 일부를 자를 수 있습니다. 글자가 잘리면 배치 조절에서 축소하거나 위치를 조정하세요.
- 앞면·덮개 이미지 배치 조절 기능은 유지했습니다.
- 이미지 데이터는 브라우저 localStorage에 저장되며 큰 파일은 저장 용량 제한이 발생할 수 있습니다.

6차 추가 변경
- 1단계 입력 화면에서 '상단 덮개 문구' 입력란 삭제
- 상단 덮개 프롬프트에서 문구 입력/표기 지시 삭제
- 문자, 글자, 숫자, 문장, 로고, 서명 등 텍스트 요소를 전부 금지
- 덮개는 지정한 색상의 균일한 단색 바탕만 생성
- 기존 191 × 36mm 생성 권장, 185 × 30mm 최종 적용, 180도 회전 및 이미지 배치 조절 기능 유지


7차 확인 및 정리
- 1단계 프롬프트 생성 화면에는 1~7번 입력 항목만 표시
- 8번 '상단 덮개 문구' 입력란은 존재하지 않음
- 앞면 및 상단 덮개 색상 선택은 유지
- 2단계 이미지 등록 및 배치 조절 기능은 변경하지 않음
- 앞면·덮개 이미지 합성 및 A4 출력 기능은 변경하지 않음


[8차 수정 사항]
- 앞면과 상단 덮개 이미지를 각각 고정된 SVG 클리핑 영역 안에서만 표시합니다.
- 상단 덮개는 180도 회전하되, 클리핑 사각형은 회전하지 않도록 이미지 회전 그룹과 클리핑 그룹을 분리했습니다.
- 따라서 덮개 이미지의 여유 영역이나 위치 조절로 이미지가 봉투 도안 밖에 나타나는 현상을 방지합니다.


[9차 수정 사항]
- 이미지 클리핑을 기존 clipPath 참조 방식에서 독립된 중첩 SVG 표시창(viewport) 방식으로 변경했습니다.
- 앞면 이미지는 185 × 75mm 표시창 안에서만 보입니다.
- 상단 덮개 이미지는 185 × 30mm 표시창 안에서만 보이며, 이미지 180도 회전은 표시창 내부에서만 적용됩니다.
- 이미지 확대·축소 및 위치 조절 기능은 유지했습니다.
- 중첩 SVG에 외부 CSS 크기 규칙이 잘못 적용되지 않도록 미리보기·인쇄 CSS 선택자를 최상위 SVG로 한정했습니다.
- A4 출력 미리보기에도 동일한 이미지 표시 제한을 적용합니다.
